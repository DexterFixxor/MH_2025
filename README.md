# Vezbe 2025
U ovom projektu konfigurisemo STM32 Nucleo-F401RE.

Ova grana pokriva samo inicijalnu konfiguraciju, odnosno, podesavanje izvora radnog takta kao i radnu frekvenciju.

Na ostalim grana je pokriveno:
- [x] Eksterni prekid (EXTI13 - plavi taster)
- [x] Vremenski prekid (TIM4 1kHz)
- [ ] Masina konacnih stanja (FSM)
- [ ] UART komunikacioni protokol
- [ ] Enkoderski interfejs i kvadraturno dekodiranje
- [ ] Odometrija
- [ ] PWM - upravljanje RC servo motorom
- [ ] H-most i upravljanje BDC motorom
- [ ] PID regulaicja
- [ ] UART + Dynamixel AX-12 motor
- [ ] IR senzor
- [ ] SPI
- [ ] I2C
- [ ] DMA + UART
